# Code

    Theory_code/        ODEs, optimal control and finite-d simulations
    Experiments_code/   benchmarks against selection policies from the literature

`Theory_code/README.md` documents layout, policy families, numerics,
runtimes.

`Experiments_code/` is one notebook `Experiments.ipynb`.


Requirements: numpy, scipy, matplotlib, jax for `Theory_code`, and numpy, scipy,
matplotlib, scikit-learn, tqdm for `Experiments_code`.
